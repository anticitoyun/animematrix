## AniMe Matrix pour Linux 2.2.2

### Changements
- Projet déplacé sur GitLab : mises à jour intégrées, bibliothèque d'animations, dépôt APT et liens du lanceur pointent vers GitLab.
- Réglages : boutons de soutien Tipeee et PayPal.

### Mise à jour depuis la 2.2.1 ou avant
Les versions précédentes cherchaient leurs mises à jour sur GitHub, qui n'existe plus : installez cette version à la main.
```
sudo apt install ./anticitoyen-rog-flare2-anime-matrix_2.2.2_all.deb
```
Dépôt APT : remplacez `anticitoyen.github.io` par `anticitoyen.gitlab.io` dans votre source APT (voir README).

### English
- Project moved to GitLab: built-in updates, animation library, APT repository and launcher links now point to GitLab.
- Settings: Tipeee and PayPal support buttons.
- Versions 2.2.1 and older looked for updates on GitHub, which is gone: install this version by hand. APT users: replace `anticitoyen.github.io` with `anticitoyen.gitlab.io` in your APT source.
