## AniMe Matrix pour Linux 2.2.3

### Changements
- Sécurité : la restauration d'une sauvegarde refuse les extensions Python (elles seraient exécutées au lancement) ; l'archive est vérifiée avant toute écriture.
- Sécurité : le jeton de la télécommande et le mot de passe OBS sont créés accessibles au seul utilisateur.
- Sécurité : les favoris webcam, écran et vidéo ne se lancent plus depuis la télécommande ; les requêtes JSON contenant NaN ou Infinity sont refusées.
- Sécurité : vitesse du démon bornée ; notifications limitées à 60 secondes et 500 caractères.
- Sécurité : les extensions ne sont chargées que si elles appartiennent à l'utilisateur et ne sont pas modifiables par d'autres comptes ; les mises à jour n'acceptent que les paquets venant de gitlab.com.
- Sécurité : assistant root des ventilateurs (chiffres ASCII seulement) ; conversion GIF avec chemins absolus.

### Mise à jour depuis la 2.2.2 ou avant
```
sudo apt install ./anticitoyen-rog-flare2-anime-matrix_2.2.3_all.deb
```
Ou, depuis le dépôt APT, les mises à jour suivent normalement.

### English
- Security: restoring a backup refuses Python extensions (they would run at launch); the archive is checked before anything is written.
- Security: the remote-control token and the OBS password are readable by the user only.
- Security: webcam, screen and video favorites no longer start from the remote control; JSON requests containing NaN or Infinity are refused.
- Security: daemon speed is bounded; notifications are limited to 60 seconds and 500 characters.
- Security: extensions load only if owned by the user and not writable by other accounts; updates accept only packages from gitlab.com.
- Security: root fan helper (ASCII digits only); GIF conversion uses absolute paths.
